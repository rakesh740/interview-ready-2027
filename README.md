# interview-ready-2027

A distributed job/task scheduler in Go, built and deployed incrementally over a 4-week interview-prep plan: gRPC submission API → persistence & reliability → Kubernetes deployment & observability → autoscaling & operators.

Architecture, design decisions, and tradeoffs will be documented here as the project grows through each week's milestone (see `CURRICULUM.md`).

## Running locally

```
make run
```

(Details filled in as `cmd/server` and `cmd/worker` are implemented in Week 1.)
